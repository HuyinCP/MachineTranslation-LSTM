# Neural Network from scratch

**Tham khảo:** [Building a Neural Network from scratch](https://codingowen.github.io/projects/neural_network_from_scratch/) — bài toán phân loại chữ số MNIST bằng mạng hai lớp và NumPy.

## Hiện có

- [Notebook Iris MLP dùng PyTorch](experiments/iris-mlp-pytorch.ipynb) được chuyển từ `MachineTraslation/MLP/`. Đây là bài tập MLP riêng trên Iris, **chưa phải** phần triển khai MNIST/NumPy theo bài tham khảo.

## Dự kiến xây dựng

1. Ký hiệu, kích thước dữ liệu và các ma trận của mạng hai lớp.
2. Forward pass, softmax, cross-entropy và backpropagation.
3. Triển khai NumPy dễ đọc, kiểm tra gradient và đánh giá trên MNIST.

Giữ notebook thử nghiệm trong `experiments/`; khi bắt đầu bản triển khai chính sẽ thêm notebook hoặc source và cập nhật README này.
