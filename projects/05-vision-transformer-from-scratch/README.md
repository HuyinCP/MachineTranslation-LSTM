# Vision Transformer (ViT) from scratch

**Tham khảo:** [Building a Vision Transformer (ViT) from scratch](https://codingowen.github.io/projects/vision_transformer/).

Thư mục này dành cho dự án ViT độc lập. Hiện chưa có bản triển khai ở đây.

## Dự kiến xây dựng

1. Chia ảnh thành patch và tạo patch embedding.
2. Thêm positional embedding và class token.
3. Xây Transformer encoder từ các khối attention và MLP.
4. Huấn luyện, đánh giá và đối chiếu kích thước tensor qua từng tầng.

Các thành phần attention chung sẽ được giải thích trước tại [dự án Self-Attention](../04-self-attention-from-scratch/README.md).
